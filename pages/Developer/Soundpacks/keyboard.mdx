# Keyboard Sound Packs
<Callout>
_Keyboard sound packs are located in `[XSOverlay install]/XSOverlay_Data/StreamingAssets/Plugins/KeyboardSounds/`_
</Callout>

***

## Creating Sound Packs
<Callout type="info">
**Requirements**
    - _Audio files must be named `backspace.ogg`, `enter.ogg`, `spacebar.ogg` and `tap.ogg`._
    - _You must include a `soundpackSettings.json` configuration file._
</Callout>
To create a sound pack, place these files in a new folder under the `KeyboardSounds` directory. Then choose it in Settings › Keyboard › [Sound Pack](/settings/keyboard#sound-pack).

***

## Sound Pack Settings
<Callout type="warning">
`soundpackSettings.json` is required. It controls the volume of the typing sounds and how much their pitch is randomized.
</Callout>

```json copy filename="soundpackSettings.json"
{
    "settings": [
        {
            // The minimum pitch when randomizing the pitch of a key press sound.
            "minimumPitchRange": 1,
            // The maximum pitch when randomizing the pitch of a key press sound.
            "maximumPitchRange": 1,
            // The overall volume of key press sounds.
            "volume": 1
        }
    ]
}
```
