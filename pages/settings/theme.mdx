# Theme

{/* section: Base_Theme */}
## Base Theme

{/* setting: UseDarkTheme */}
### Use Dark Theme
<SettingMeta default="On" />

Switches the UI between dark and light themes.

{/* setting: AdaptiveColor */}
### Adaptive Color
<SettingMeta default="10%" range="0% – 100%" />

Tints the UI's background tones with the hue of your [Accent Color](#accent-color). At 0% the background is neutral gray.

{/* setting: MediaThemeing */}
### Use Media Theme
<SettingMeta default="Off" />

Themes the UI with colors taken from the album art of the media that's playing, while the wrist media player is open.

{/* section: Accent_Color */}
## Accent Color
