# Wrist Overlay

The wrist overlay sits on the back of your left hand. To put it on your right hand, change [Dominant Hand](/settings/general#dominant-hand).

<Screenshot image={wristImage} alt="Wrist Overlay" />

| Element | Description |
| --- | --- |
| Clock | The time, the date, and how long you've been in VR. Formatted by the [Date / Time](/settings/wrist#date--time) settings. |
| Layout Mode | Opens or closes [Layout Mode](layout-mode). |
| Media Player | Shows or hides the media player. |
| Performance | Shows or hides CPU, GPU, memory and frame time stats. |
| Now playing | The track playing on your PC. |
| Media controls | Previous, play/pause, and next. |
| Battery | Battery levels of your connected controllers and trackers. Hover to see each device's estimated time remaining, and click to switch between percentages and time remaining. See [Battery Widget](/settings/wrist#battery-widget). |
