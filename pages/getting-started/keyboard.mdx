# Keyboard

Open the keyboard with the Keyboard button on the [Layout Mode toolbar](layout-mode#toolbar).

<Screenshot image={keyboardImage} alt="Keyboard" />

| # | Element | Description |
| --- | --- | --- |
| 1 | Speech to text | Starts voice recognition. What you say appears in the composer. Set the microphone in [Voice](/settings/keyboard#voice) settings. |
| 2 | Composer | Type or dictate text before sending it. |
| 3 | Send | Sends the composed text to the focused window. |
| 4 | Clear | Clears the composer. |
| 5 | Pin | Keeps the keyboard visible when Layout Mode is closed, like an overlay's [Pin](/getting-started/overlays#pin). |
| 6 | Lock | Locks the keyboard, like an overlay's [Lock](/getting-started/overlays#lock). |
| 7 | Settings | Opens XSOverlay's [settings](/settings/general). |
| 8 | Close | Hides the keyboard. |
| 9 | Escape | The Escape key. |
| 10 | Copy | Copies the selection. |
| 11 | Paste | Pastes from the clipboard. |
