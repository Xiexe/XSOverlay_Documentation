OSC (Open Sound Control) is a protocol for communication between applications. By default, XSOverlay sends OSC messages to port `9000` and listens for OSC messages on port `9001`.
These ports can be changed by editing `ExternalMessageAPIConfig.json` in `[XSOverlay install]/XSOverlay_Data/StreamingAssets/Plugins/Config/`.


### OSC Configuration

| Option | Description | Default Value |
| --- | --- | --- |
| `OscSendPort` | The port XSOverlay sends OSC messages to. | `9000` |
| `OscListenPort` | The port XSOverlay listens for OSC messages on. | `9001` |
| `OscOutputPath` | The base OSC address prefixed to each parameter name. | `/avatar/parameters/` |

Restart XSOverlay after changing this file.

<Callout>
Use a port number between `20000` and `49150`. Ports outside this range may conflict with ports reserved by your operating system or other services.
</Callout>

### OSC Parameters

The following OSC parameters are sent by XSOverlay:

| Parameter | Description | Type |
| --- | --- | --- |
| `hmdBattery` | Headset battery level (range: 0 - 1) | Float |
| `leftControllerBattery` | Left controller battery level (range: 0 - 1) | Float |
| `rightControllerBattery` | Right controller battery level (range: 0 - 1) | Float |
| `averageControllerBattery` | Average controller battery level (range: 0 - 1) | Float |
| `averageTrackerBattery` | Average tracker battery level (range: 0 - 1) | Float |
| `isOverlayOpen` | `true` while any overlay is open, otherwise `false` | Boolean |
| `isKeyboardOpen` | `true` while the keyboard is open, otherwise `false` | Boolean |
| `isWristVisible` | `true` while the wrist overlay is visible, otherwise `false` | Boolean |
| `openOverlayCount` | The number of open overlays (range: 0 - 255) | Integer |

### VRChat (OSCQuery)

While VRChat is running, XSOverlay finds it automatically with [OSCQuery](https://github.com/Vidvox/OSCQueryProposal), so these features need no port setup:

- **Chatbox**: the keyboard can send text to your VRChat chatbox instead of the focused window, up to 144 characters.
- **Microphone**: speech to text mutes your VRChat microphone while it's listening, then restores it to how it was.

For more information on the OSC protocol and how to integrate it into your application, see the [OSC documentation](https://opensoundcontrol.org/introduction-osc).
